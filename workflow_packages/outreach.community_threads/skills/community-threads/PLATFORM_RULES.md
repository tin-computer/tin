# Platform rules

These are baseline norms. A community's live rules win: check the subreddit sidebar, wiki or
pinned post, or the forum's guidelines, before keeping a thread. If they forbid vendors, tool
mentions or links, drop the thread.

## Reddit

- Many subreddits remove self-promotion and posts or comments with shortened, affiliate or
  tracking links. Link to a plain docs or repository page, never a sales page.
- Reply only where someone asked for a tool or help; never start a new promotional post.
- Technical subreddits expect specifics: how it works, what it costs to run, how it fails.
  Code or config in the reply beats a link.
- Never send direct messages to people who posted.

## Hacker News

- State your relationship to the product plainly in the reply.
- Give real substance first; the product gets at most one closing sentence.
- Name better alternatives honestly when they fit the asker's case.
- Never coordinate votes or post from more than one account.

## GitHub Discussions and issues

- Never use a project's bug report to advertise a product.
- In Discussions, answer "is there a library or service for X" with how the tool integrates,
  a link to its repository or docs, and the disclosure.

## Public forums

- Follow the forum's own rules on vendor participation; many allow it only in a marketplace or
  showcase category.
