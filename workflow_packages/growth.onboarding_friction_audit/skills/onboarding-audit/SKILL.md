name: onboarding-audit
description: Identify friction points and missing prerequisites in the developer onboarding flow.
---

Read the project's README, quickstart guides, and example code. Put yourself in the shoes of the specified target developer persona.

Simulate following the onboarding steps from start to finish. Focus specifically on "Time-to-First-Value" (TTFV) - how long and how many steps it takes for a new developer to see the product working.

In your report, you must include:
1. **The Critical Path**: A numbered list of the exact steps required to get started.
2. **Friction Points**: Any steps that require external context, missing dependencies, undocumented API keys, or unclear instructions.
3. **Missing Prerequisites**: Things the developer is expected to have or know but aren't explicitly stated.
4. **Concrete Fixes**: Three specific, actionable recommendations to shorten the TTFV.

Write only the declared report at `reports/ONBOARDING_FRICTION_AUDIT.md`. Do not invent facts or assume steps work if the documentation is broken or incomplete.
